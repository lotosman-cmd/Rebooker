# Rebooker

اپلیکیشن اندرویدی فارسی برای سامان‌دهی پروژه‌ها، صفحات و پاسخ‌های تکراری؛ با تأیید مرحله‌ای و ذخیره‌سازی محلی.

## امکانات نسخه فعلی
- ایجاد و مدیریت پروژه‌ها
- ایجاد صفحات متعدد در هر پروژه
- ثبت، ویرایش و حذف پرسش و پاسخ
- الزام تأیید هر صفحه پیش از ادامه و ثبت نهایی
- قفل پروژه پس از ثبت نهایی و امکان بازگشایی برای ویرایش
- بانک پاسخ مستقل با جست‌وجوی سؤال و پاسخ
- پشتیبان‌گیری و بازیابی اطلاعات با فایل JSON
- رابط فارسی و راست‌چین، مناسب تلفن همراه

## ساخت خودکار APK
با هر push به شاخه `main` یا اجرای دستی workflow با نام **Build Rebooker APK**، مراحل زیر انجام می‌شود:
1. بررسی نحو JavaScript تعبیه‌شده در برنامه
2. ساخت APK آزمایشی با JDK 17 و Gradle 8.9
3. کنترل وجود فایل APK و ثبت اندازه و SHA-256
4. انتشار فایل به‌صورت GitHub Actions artifact با نگهداری ۳۰ روزه

فایل خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

برای دریافت APK، وارد بخش Actions مخزن شوید، آخرین اجرای موفق **Build Rebooker APK** را باز کنید و artifact با نام `Rebooker-debug-apk` را دریافت کنید.

## نکات داده و حریم خصوصی
اطلاعات پروژه‌ها در فضای ذخیره‌سازی محلی WebView روی همان دستگاه نگهداری می‌شود و به سرور ارسال نمی‌شود. پاک‌کردن داده‌های برنامه یا حذف برنامه ممکن است اطلاعات را از بین ببرد؛ نسخه پشتیبان JSON را به‌طور منظم خارج از برنامه نگهداری کنید.

## وضعیت انتشار
نسخه فعلی، نسخه آزمایشی (debug) است. پیش از انتشار عمومی، باید ساخت موفق، نصب واقعی روی دستگاه، پایداری ذخیره‌سازی پس از بستن و بازکردن برنامه، و مسیر پشتیبان‌گیری/بازیابی روی چند دستگاه بررسی شود. نسخه release امضاشده هنوز تولید نشده است.
