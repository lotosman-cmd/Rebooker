# Rebooker

اپلیکیشن اندرویدی فارسی برای ثبت پروژه‌ها، صفحات، پرسش‌وپاسخ‌ها و تأیید مرحله‌ای.

## ساخت APK
این پروژه با Android Gradle Plugin 8.7.3 و JDK 17 ساخته می‌شود. با push روی شاخه `main` یا اجرای دستی workflow با نام **Build Rebooker APK**، فایل debug APK به‌عنوان GitHub Actions artifact منتشر می‌شود.

## امکانات نسخه پایه
- ساخت و مدیریت پروژه‌ها
- ثبت، ویرایش و حذف پرسش و پاسخ
- الزام تأیید هر صفحه پیش از ادامه/ثبت نهایی
- ذخیره محلی روی دستگاه
- جست‌وجوی بانک پاسخ‌ها
- پشتیبان‌گیری و بازیابی JSON

اطلاعات فقط در حافظه محلی برنامه نگهداری می‌شود. حذف داده برنامه می‌تواند اطلاعات را از بین ببرد؛ نسخه پشتیبان منظم توصیه می‌شود.
